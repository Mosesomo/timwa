## Technical Elements Google Crawls

### Sitemap
Google finds at: `/sitemap.xml`
Contains: All 6 main pages with change frequency and priority

### Robots.txt
Google sees at: `/robots.txt`
- Allows Googlebot to crawl everything
- Links to sitemap
- Blocks admin routes

### Schema Markup
Google validates:
- LocalBusiness (with address, phone, email)
- Organization (with founder, founding date)
- Service schemas (for each service)
- BreadcrumbList (navigation)
- FAQ schema (common questions)

### Meta Tags Google Sees
Every page has:
- Unique title (50-60 chars)
- Meta description (150-160 chars)
- Keywords (comma-separated)
- Canonical URL (https://timwafisheries.com)
- OpenGraph image (1200x630px)
- Twitter card tags
- Viewport tag (mobile responsive)

### Performance Metrics Google Crawls
- Page load speed
- Core Web Vitals (LCP, FID, CLS)
- Mobile responsiveness
- Image optimization
- Font loading
- JavaScript execution
